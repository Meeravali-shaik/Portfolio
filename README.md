# Meeravali Shaik - AI/ML Portfolio Website

This is a modern, responsive, and professional portfolio website template designed for an Artificial Intelligence & Machine Learning Engineer. It features a dark/light mode toggle, smooth scrolling, and dynamic animations.

## 🚀 Features

-   **Responsive Design**: Mobile-first approach, works seamlessly on all devices.
-   **Dark/Light Mode**: Toggle between themes with a click.
-   **Animations**: Integrated AOS (Animate On Scroll) and Typed.js for dynamic text.
-   **Sections**:
    -   Hero (Introduction & Resume Download)
    -   About Me (Education & Career Objective)
    -   Skills (Progress bars & Tags)
    -   Projects (Showcase with GitHub/Live links)
    -   Certifications (Grid layout)
    -   Contact (Form & Social Links)

## 🛠 Tech Stack

-   **HTML5**
-   **CSS3** (Flexbox, Grid, Custom Properties)
-   **JavaScript** (ES6+)
-   **AOS** (Animation Library)
-   **Typed.js** (Typewriter Effect)
-   **Font Awesome** (Icons)

## 📂 Folder Structure

```
Meeravali_portfolio/
├── index.html       # Main HTML file
├── style.css        # Core styles
├── light-mode.css   # Light theme overrides (imported in style.css)
├── script.js        # JavaScript logic (Toggle, Animations, interactions)
└── README.md        # Project documentation
```

## 🔧 How to Use

1.  **Clone or Download**: Download this folder to your local machine.
2.  **Open**: Double-click `index.html` to view the website in your browser.
3.  **Customize**:
    -   Open `index.html` in a code editor (VS Code, Sublime, etc.).
    -   Replace all `NULL`, `#`, and placeholder text with your real data.
    -   Replace placeholder images if you add any.
    -   Update the "Download Resume" link to point to your actual `resume.pdf` file.

## 📦 Deployment

You can deploy this site for free using GitHub Pages or Vercel.

### GitHub Pages
1.  Create a new repository on GitHub.
2.  Push these files to the repository.
3.  Go to **Settings** > **Pages**.
4.  Select the `main` branch and click **Save**.
5.  Your site will be live at `https://yourusername.github.io/repo-name`.

### Vercel
1.  Go to [Vercel](https://vercel.com/).
2.  Sign up/Login and click **Add New Project**.
3.  Import your GitHub repository.
4.  Click **Deploy**.

## 🎨 Customization Tips

-   **Colors**: Change the `--accent` variable in `style.css` to change the primary theme color.
-   **Fonts**: The site uses 'Outfit' and 'Roboto Mono' from Google Fonts. You can change the `link` in `index.html` and variables in `style.css`.
